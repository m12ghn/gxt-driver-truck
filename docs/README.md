# GXT Driver Truck

## Mô tả

Hệ thống Check In / Check Out dành cho tài xế dự án GXT.

## Mục tiêu

- Quản lý Check In / Check Out
- Kiểm soát GPS
- Kiểm soát đúng kho
- Kiểm soát đúng giờ
- Lưu ảnh ODO
- Lưu ảnh tình trạng xe
- Dashboard quản lý
- Báo cáo KPI
