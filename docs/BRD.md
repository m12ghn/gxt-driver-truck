# GXT Driver Truck

## 1. Mục đích

Xây dựng hệ thống Check In / Check Out dành cho tài xế dự án GXT.

Hệ thống giúp:

- Kiểm soát đúng người
- Kiểm soát đúng xe
- Kiểm soát đúng kho
- Kiểm soát đúng giờ
- Lưu hình ảnh ODO
- Lưu hình ảnh tình trạng xe
- Dashboard theo thời gian thực

---

## 2. Đối tượng sử dụng

### Driver

- Đăng nhập
- Check In
- Check Out
- Xem lịch sử

### GSVT

- Theo dõi Dashboard
- Theo dõi Check In
- Theo dõi Check Out
- Xem hình ảnh

### Manager

- Xem Dashboard
- Xem KPI
- Xuất báo cáo
